# MightySpares1/.github

Organisation profile for **Mighty Spares**. GitHub shows `profile/README.md` on the org page.

- `profile/README.md` — the profile page
- `profile/assets/*.svg` — animated banners (pure SVG + CSS, no JS; respects `prefers-reduced-motion`)
- `tools/*.py` — generators for the SVGs (`cd tools && python3 build_hero.py` etc.)
